Upload these 5 ambulances to eBay

File: ebay-ambulances-create-listings.csv

1. Open https://www.ebay.com/sh/reports/uploads
2. Get template → Listings → Create new listings → CSV (optional — or try our file first)
3. Upload template → choose this CSV → template type: Create new listings
4. If eBay rejects for Business Policies, open the CSV and fill:
   PaymentProfileName, ShippingProfileName, ReturnProfileName
   with the EXACT names from Seller Hub → Account → Business Policies
5. Photos use public URLs on prince-george-transport.pages.dev — keep those online
6. After upload, check the results report for any failed rows

Notes:
- Price: $1500.00 each, Best Offer enabled
- ConditionID 7000 = For parts or not working (does not run)
- ShippingType Freight = buyer arranges transport / pickup after eBay payment
- No cash / at-site payment language in descriptions
