## Steps

### 1. Register

1. Open https://signup.ebay.com/pa/crte  
2. Choose **Create a business account** (not personal)  
3. Enter email + strong password → verify email  
4. Enter business name, type, address, phone  
5. Add beneficial owner / contact info when asked  

### 2. Become a seller + payouts

1. Go to https://www.ebay.com/sh/lst/active (Seller Hub)  
2. Start selling / register as seller when prompted  
3. Link **business checking** (name must match)  
4. Complete any ID / document requests eBay emails you  

### 3. Business policies (required before volume selling)

Seller Hub → **Settings / Account** → **Business policies**:

- Payment policy  
- Shipping policy (include **Local pickup — Blythewood, SC**)  
- Return policy (e.g. no returns / as-is for used EMS gear)

### 4. Wire to this website
